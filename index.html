📖 如何 3 分鐘免費申請與設定 Firebase (電腦與手機同步教學) 免費額度終身足夠使用
1
登入 Firebase 控制台： 前往 Firebase Console (點此前往)，以平常使用的 Google 帳號登入。
2
建立專案： 點擊「建立專案 (Create Project)」，輸入專案名稱（例如 fxg-system），Google Analytics 可選擇取消勾選，點「建立」等待幾秒完成。
3
啟用 Realtime Database (即時資料庫)： 進入專案後，在左側功能表點「建構 (Build)」➔「Realtime Database」➔ 點「建立資料庫 (Create Database)」➔ 地點選預設或新加坡，在安全規則頁面勾選「以測試模式啟動 (Test mode)」並按啟用。
4
複製網頁金鑰並貼上： 點擊畫面左上角 ⚙️「專案設定 (Project settings)」➔ 往下滑在「您的應用程式」中點選網頁圖示 </> ➔ 隨意填個名稱（如 web）並註冊 ➔ 複製畫面中的 firebaseConfig = { ... } 程式碼，貼回上方輸入框，按「⚡ 儲存並連線」！
✨ 手機免重新設定秘訣：電腦連線成功後，點擊上方的「複製手機同步專屬網址」，透過 LINE 或訊息傳到手機打開，手機就會自動同步連線，完全不需要在手機上手動複製貼上！
